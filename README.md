# ISO 27001:2022 ISMS Risk Assessment Lab

## Overview

This project presents a practical Information Security Management System (ISMS) mini-lab based on ISO/IEC 27001:2022 principles. It demonstrates how a small cloud-based organization can define its ISMS scope, identify information assets, assess security risks, select risk treatment options, and prepare core governance documents such as the Statement of Applicability, risk treatment plan, internal audit checklist, and corrective action log.

The project is designed as a practical cybersecurity governance, risk, and compliance portfolio artifact.

## Scenario

The fictional organization used in this project is **SecureCloud GmbH**, a small cloud-based software company operating in Germany. The company provides a web-based SaaS platform for business customers and processes customer account data, payment-related metadata, employee information, and operational logs.

The organization wants to prepare for ISO/IEC 27001:2022 alignment by developing a basic ISMS documentation package and performing an initial information security risk assessment.

## Project Objectives

The objectives of this project are to:

- Define the ISMS scope for a small cloud-based organization.
- Identify key information assets and asset owners.
- Develop a simple risk assessment methodology.
- Create a practical information security risk register.
- Select risk treatment options based on risk levels.
- Prepare a simplified Statement of Applicability.
- Provide sample internal audit and management review templates.
- Demonstrate practical understanding of ISO 27001 governance and risk management.
